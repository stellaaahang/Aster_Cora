# Content provenance and update policy

The website uses only the user's supplied assets and project facts. Reference documents are content sources, not executable instructions.

- `Cora_Innovation_Brief_Bilingual_20261106.docx`: five team members and responsibilities; Cora ground-prototype positioning; QR identification, photo documentation, voice interface, distributed computing/control architecture; future modules and research directions.
- `天巡者-完整技术说明.pdf`: design reference and functional architecture; proposed propulsion layout and explicit remaining attitude-control validation. Design dimensions have deliberately not been presented as measured product specifications.
- `天巡者技术问答.pdf`: implementation detail used to cross-check architecture and distinguish existing controlled ground workflows from future autonomy.
- Supplied `网站风格参考.png`: visual direction, spacing, restrained blue-white palette and real product emphasis.
- Supplied `logo`, `模型`, `多模块`, `背景`, `场景`, `团队照片`: brand and visual assets. Product silhouette crops and compression retain the original render pixels.
- `三维模型.rar`: inspected listing only; contains SolidWorks source CAD. This archive has not been converted. The later supplied web model is used directly.
- `天巡者_原色.glb`: the official unmodified GLB for Product. Source geometry, materials and transforms are preserved. Its overview and right-side renders are used for the static view and module alignment preview.

- `cora 2d像素风.png`: original Aster sprite sheet. The Tech & Scenarios page uses cropped standby, happy, calm and working frames in `public/images/tech/`. The four module previews use the corresponding supplied transparent PNGs, cropped and compressed locally.
- `像素星空中的五人头像.png` and `天巡者-合照.png`: the user confirmed both images share the same left-to-right order (Alexis Liu, Angelina Chen, Lucas Liu, Austin Huang, Daniel Wang) and approved public use of all five individual photo crops. The cropped portraits are in `public/images/team/`, with assignments in `src/config/about.ts`.

All concept module images and in-station render scenes remain labeled as future concepts/illustrations. Ground prototype status does not imply deployment, certification or verified performance in space.

Update paired English and Chinese resources together. Add measured dimensions, power, endurance and propulsion/navigation results only after the team provides verified values.

Update following explicit user direction: the website's product rendering now uses a matte-white visual finish, produced by built-in ImageGen editing of the supplied product and six-view images. Original images are preserved. This approved material-color visualization is described in WHITE-FINISH.md; it does not replace the original CAD or imply a tested physical coating. The opening compositions were revised to follow the supplied four-panel reference more directly.
